# SUPH AI - Veb Sayt Versiyası (Node.js & Express)

Google Gemini ilə təchiz edilmiş müasir, tünd göy və bənövşəyi dizaynlı süni intellekt çatbot saytı.

## Quraşdırma və İşə Salma

1. **Kitabxanaları quraşdırın:**
   ```bash
   npm install
   ```

2. **API Açarını təyin edin:**
   `.env` faylı yaradın və Gemini API açarınızı əlavə edin:
   ```env
   GEMINI_API_KEY=Sizin_Gemini_API_Acariniz
   PORT=3000
   ```

3. **Saytı işə salın:**
   ```bash
   node server.js
   ```

4. **Brauzerdə açın:**
   `http://localhost:3000`
